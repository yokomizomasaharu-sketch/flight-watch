# フライトウォッチ

航空券・ホテル・航空券＋ホテルのセールやおすすめ便を眺めて、見積書・領収書・予約控えをまとめておくための個人用PWAです。

**公開URL**: https://yokomizomasaharu-sketch.github.io/flight-watch/

## 使い方
1. iPhoneのSafariで上のURLを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動（アプリのように全画面で開きます）

## 機能
- ✈️ **監視**: セール・実運賃・ホテル・パックのカード一覧（対象／エリア／開催中／★で絞り込み）
- 🎫 **予約**: 航空券・ホテル・パックの控え、経費（確定申告）バッジ、領収書の登録・閲覧・印刷、発行した見積書の一覧
- 🎯 **リクエスト**: 種別（航空券／ホテル／パック）・日程・予算・座席・手荷物・支払い方法（登録カード／コンビニ払い）を入れて、監視の依頼文を作成。進め方は「確認カード／見積書を発行して確認後に予約／条件内なら自動予約」
- ⚙️ **設定**: パスポートの有効期限アラート、支払い方法の登録（カードは呼び名と末尾4桁のみ・コンビニと払込票の通知先）、会員番号、4桁PINロック
- 🔒 **共有モード**: 予約・パスポート・会員番号・支払い方法・見積書・領収書を画面から消して、スクショ共有しても個人情報が映らない状態に

## データの扱い
- 入力した内容は**この端末の localStorage だけ**に保存されます。サーバーへ送信しません。
- 初期状態は予約0件・個人情報0件です。URLを共有しても、あなたの入力が相手に渡ることはありません。
- カード番号（16桁）・有効期限・CVCは入力も保存もできません（呼び名と末尾4桁のみ）。
- 公開されているのはセール情報（`flight_data.js`）だけです。

## 構成
- `index.html` / `app.js` / `flight_data.js`: アプリ本体と監視データ
- `manifest.json` / `sw.js` / `pwa.js` / `icons/`: PWA（ホーム画面追加・オフライン起動）

監視データは `flight_data.js` の `deals` 配列を更新すると反映されます（`newIds` に入れた id は NEW バッジ付き）。
